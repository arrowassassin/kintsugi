Paperscope — Local-First Document Search with Exact Citations

Hybrid FTS5 + sqlite-vec search. Extractive answers with page-level citations. 15+ formats. 100+ languages. MCP server for LLM integration. Zero telemetry. Runs entirely offline.

Install via Cargo install.sh View Source
paperscope search — ~/docs/research
$ paper index --root ~/docs
$ ✓ Index complete
$ paper answer "What does the paper say about transformer attention mechanisms?"
💡 Answer: The paper describes multi-head attention as...
📄 Citation: vaswani2017attention.pdf, p. 3-4, §3.2
📄 Citation: devlin2019bert.pdf, p. 5, §2.1
$ paper search "attention is all you need" --limit 5
1. vaswani2017attention.pdf — 0.94 relevance
2. devlin2019bert.pdf — 0.87 relevance
3. radford2019gpt2.pdf — 0.72 relevance
Installation

Get Running in Seconds

Single binary, zero dependencies. Install via Cargo or download a release.

One-line install

Everything installs and configures automatically — no manual steps needed. 

$ curl --proto '=https' --tlsv1.2 -LsSf https://github.com/arrowassassin/paperscope/releases/latest/download/paper-installer.sh | sh

From Source

Clone and build with Cargo. Requires Rust 1.75+.

$ git clone https://github.com/arrowassassin/paperscope
$ cd paperscope
$ cargo build --release
Capabilities

Search That Shows Its Work

Every answer cites its source. Every result is traceable. Answers are extractive by default.

Hybrid FTS5 + Vector Search

Combines SQLite FTS5 (exact keyword matching) with sqlite-vec (semantic similarity). Best of both worlds: precision + recall.

Extractive Answers with Citations

Answers quote the exact source text with document name, page number, and section. No generated text — only what's in your documents.

MCP Server for LLMs

Run paper serve --mcp to expose search as an MCP server. Claude, Cursor, and other agents can query your docs directly.

100+ Languages

The optional multilingual-e5-small model supports 100 languages. Query in one language and find documents written in another.

15+ Document Formats

PDF, EPUB, DOCX, DOC, PPTX, XLSX, HTML, MD, TXT, RTF, ODT, ODP, ODS, CSV, JSON. More via pluggable extractors.

Local-First, Zero Telemetry

Your documents never leave your machine. No cloud, no analytics, no accounts. Full control over your data and search index.

Available Models

BGE Small English (Default)

English semantic search with 384-dimensional embeddings. 134 MB.

$ paper models install bge-small-en-v1.5

Multilingual E5 Small

Multilingual semantic search across 100 languages. 487 MB.

Cross-encoder reranking for search results. 1.13 GB.

$ paper models install bge-reranker-base
Integration

MCP Server for AI Agents

Expose your document index to any MCP-compatible agent. Zero-config, secure, local.

Quick Start

Add to your MCP client config (Claude Desktop, Cursor, etc.):

claude_desktop_config.json 
{
  "mcpServers": {
    "paperscope": {
      "command": "paper",
      "args": ["serve", "--mcp", "--root", "~/Documents"]
    }
  }
}
