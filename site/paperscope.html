Set up once.
Then forget it exists.

The first command finishes setup: a background indexer, the default model, and your first folders. Nothing else to configure, and nothing to remember.

STEP 01

Install the binary

One command, or brew / cargo. No runtime, no daemon to babysit, no account.

STEP 02

First run primes itself

Registers the indexer as a user service, downloads the 134 MB embedding model, and indexes Documents, Downloads and Desktop.

STEP 03

Ask, forever

Incremental passes every five minutes, a full pass at 3 AM. Add folders in plain English through your agent, or with paper add-root.

Answers you can check.

A plausible quote from the wrong page is worse than no answer. Paper is built around that sentence.

Citations
Every hit resolves to path, page and line. Answers are extractive: source text first, then a short summary — never a generated quote.
Retrieval
SQLite FTS5 plus vector search, fused by rank. Keyword precision when the words matter; semantic recall when they don't. Low-confidence matches are dropped, not answered.
Privacy
Your index never leaves the machine. No accounts, no telemetry, no background upload. PAPER_OFFLINE=1 forbids the network outright.
Agents
An MCP server, not an API key. Claude and other MCP clients can search, read, index new folders and report status — with path vetting that keeps prompt injections away from .ssh and .aws.
Formats
PDF pages, DOCX paragraphs, scans, spreadsheets, slides, ebooks. English by default; 100+ languages with one extra model.

Your agent gets a librarian.

Point any MCP client at Paper and your assistant stops guessing about your files. It can search the index, open the cited span, and add a new folder to the index — the same controls you have in the terminal.

claude_desktop_config.json 
{
  "mcpServers": {
    "paper": { "command": "paper",
               "args": ["serve", "--mcp"] }
  }
}

Prefer a one-click install? The Claude Code plugin bundles the binary and the skill: paperscope-plugin.zip.

Eight MCP tools, same binary
search_documentsHybrid keyword + vector search with date, type and path filters.
answer_documentsExtractive answer with citations, or an honest “not found”.
read_sourceRead the exact cited span back, inside the configured roots.
list_sourcesBrowse what is indexed and when it last changed.
index_documentsIndex a specific file or folder on the agent’s request.
index_statusReport counts, current roots and whether a pass is running.
add_index_rootPersist a new folder to the index configuration.
remove_index_rootStop indexing a folder without deleting anything on disk.

What it reads,
and how deep.

Native extractors keep the structure: PDF pages, DOCX paragraphs, spreadsheet cells, slide numbers. That structure is what makes a citation trustworthy.

Documents
PDF (exact page), DOCX (paragraph ranges), ODT, RTF, Markdown, TXT
Structured
XLSX, CSV, JSON, HTML, PPTX, ODP, ODS
Books
EPUB, with chapter anchors
Scans
Optional OCR for images and image-only PDFs
Languages
English by default; 100+ with multilingual-e5-small, including cross-lingual search

bge-small-en
Default · 134 MB. Downloads automatically on first run. English semantic search.
multilingual-e5
487 MB. 100 languages; ask in English, find the Japanese contract.
bge-reranker
1.13 GB. Optional cross-encoder pass for the last few percent of precision.
Runtime
Embeddings run in-process on CPU. No Python, no server, no GPU required.
Offline
Models are fetched once, or installed from release assets; after that the network can stay off.
