Zero-touch setup

Install once. It handles the rest.

The first command starts a background service, downloads the embedding model, finds your documents and indexes them. No config file to write.

1

Install the binary

One command. No compiler, no Python, no GPU. The same build runs on macOS, Linux and Windows.

2

It configures itself

A launchd or systemd service starts in the background and fetches both models: bge-small (134 MB), then the reranker (1.13 GB).

3

Your files get indexed

Downloads, Documents and Desktop are walked recursively. New and changed files are picked up incrementally.

Answers you can check

Every claim carries its source.

No generated paragraph you have to trust. Paper returns ranked passages with a citation you can open, plus the retrieval scores behind the ranking.

  • File, page, line. The citation points at the passage, not the document.
  • Hybrid retrieval. BM25 and dense embeddings, fused, then reranked.
  • No answer invention. If nothing scores, it says so instead of guessing.

Built for real archives

Small binary. Serious retrieval.

Everything runs in-process on CPU. No server to host, no vector database to operate, no per-seat bill.

15+ formats

PDF, DOCX, PPTX, XLSX, EPUB, Markdown, HTML, RTF, ODT, CSV, EML, plain text and more.

100+ languages

ICU and Lindera segmentation for CJK, Thai, Lao, Myanmar, plus multilingual embeddings.

CLI that reads well

Search, cite, open a source, ask for an extract. Colour output when attached to a terminal.

MCP for agents

Drop it into Claude Code or any MCP client. Eight tools, including adding folders on request.

Incremental daemon

Watches roots in the background and re-indexes only what changed. idempotent, crash-safe.

Nothing leaves the machine

No accounts, no analytics, no remote API. PAPER_OFFLINE=1 forbids every network call.

Agent-native

Give your agent a memory of your files.

Paper is an MCP server. Your agent can search, read sources, and expand the index itself. Ask it to “index my research folder” and it has the tool for that.

search_documentsRanked passages with citations
read_sourceOpen the exact cited passage
answer_documentsExtract with source grounding
list_sourcesEnumerate indexed documents
index_documentsIndex a file or folder now
index_statusProgress, counts and roots
add_index_rootPersist a new folder to watch
remove_index_rootStop watching a folder
{ "mcpServers": { "paper": { "command": "paper", "args": ["serve", "--mcp"] } } }

Claude Code plugin bundles the binary and this config. No separate install step.

Install

Pick your channel.

All channels run the same build. The first command you run sets up the service, model and index for you.

Shell installer

recommended
curl -fsSL https://kintsugi.tools/paper.sh | sh

macOS and Linux. Detects architecture, verifies SHA-256.

Homebrew

macOS · Linux
brew install arrowassassin/tap/paper

Managed by Homebrew, upgrades with brew upgrade.

Cargo

Rust 1.94+
cargo install paperscope

Builds from source. No C++ compiler required since 0.2.5.

Claude plugin

agent
paperscope-plugin.zip

Bundles the binary, the MCP server and the skill. Download.

Windows: run the PowerShell installer from the latest release. Prefer a single file? Every platform tarball is on the release page with checksums.
